2. Formulación y Modelos Teóricos de la Guía de Trabajo

3.1. Deducción y Cálculo de la Toxicidad Aguda Oral de la Mezcla (ETAm)

Fórmula de aditividad ponderada del Sistema Globalmente Armonizado (SGA / GHS):

100 / ETAm = Σ (Ci / ETAi) = (C1 / ETA1) + (C2 / ETA2) + ... + (Cn / ETAn)

* En caso de componentes desconocidos (> 10% acumulado): ETAm = (100 - Cdesconocido) / Σ (Ci / ETAi).

3.2. Deducción y Cálculo del Límite Inferior de Explosividad (LELmezcla)

Fórmula termodinámica de Le Chatelier para mezclas de vapores inflamables:

LELmezcla = 100 / [ Σ (yi / LELi) ]
yi = (ni / ntotal) × 100%      con   Σ yi = 100%

3.3. Cinética de Evaporación de Acetona y Concentración en Recinto Confinado

Escenario: Derrame de Acetona pura (M = 58.080 g/mol) en charco de área A = 2.50 m2 en sala de almacenamiento de V = 120.0 m3. Ventilación: Q = 0.450 m3/s, factor de mezcla km = 0.650, velocidad de aire u = 0.200 m/s, T = 298.15 K (25.0 °C) y P = 101325 Pa.

  1. 1. Presión de vapor de saturación mediante Antoine (P*):
    log10 P* [mmHg] = A - [ B / (T [°C] + C) ]   ⇒   P* [Pa] = P* [mmHg] × (101325 / 760.0)
  2. 2. Coeficiente de transferencia convectiva de masa (K):
    K = 0.00478 · u0.78
  3. 3. Tasa de emisión másica superficial (W):
    W = (M · K · A · P*) / (R · T)    [g/s]
  4. 4. Concentración en régimen permanente (Css):
    Css = W / (Q · km)    [mg/m3]
  5. 5. Conversión a partes por millón volumétricas (Css [ppmv]):
    Css [ppmv] = (Css [mg/m3] · 24.45) / M

3.4. Diagnóstico Comparativo de Exposición Ocupacional y Riesgo ATEX

Modelos analíticos de estimación del índice de sobreexposición y porcentaje del límite explosivo:

  • Índice de Exposición Toxicológica (I):
    I = Css / TLV-TWAsustancia
    Dictamen Forense: Condición de cumplimiento si I ≤ 1.0 (zona conforme). Si I > 1.0 se determina sobreexposición crítica, paro técnico y evacuación mandatoria con ERA/SCBA.
  • Porcentaje del Límite de Inflamabilidad (% LEL):
    % LEL = (Css [ppmv] / LEL [ppmv]) × 100%
    Dictamen ATEX: Margen de seguridad preventiva internacional estipula operación segura con % LEL < 10% a 20%. Exceder este rango implica riesgo latente de deflagración en caso de cesar la ventilación mecánica.

Resolución Analítica Paso a Paso Oficial

3.1. Cálculo de Toxicidad Aguda Oral (ETAm)

Sustituyendo fracciones másicas y dosis letales:

100 / ETAm = (60.00 / 5800.0) + (15.00 / 100.00) + (25.00 / 5580.0)
C1/ETA1 = 0.0103448 kg/mg
C2/ETA2 = 0.1500000 kg/mg
C3/ETA3 = 0.0044803 kg/mg
Σ (Ci / ETAi) = 0.0103448 + 0.1500000 + 0.0044803 = 0.1648251 kg/mg

ETAm = 100 / 0.1648251 = 606.7037 mg/kg → Categoría 4 de Toxicidad Aguda Oral (GHS07, Palabra: ATENCIÓN, H302: Nocivo en caso de ingestión).

3.2. Cálculo del Límite Inferior de Explosividad (LELmezcla)

Cálculo molar sobre base de 100.0 g:

n1 = 60.00 / 58.080 = 1.03306 mol;   n2 = 15.00 / 32.042 = 0.46814 mol;   n3 = 25.00 / 92.141 = 0.27132 mol
ntotal = 1.03306 + 0.46814 + 0.27132 = 1.77252 mol
y1 = 58.2825%;   y2 = 26.4110%;   y3 = 15.3065% (Σ yi = 100.0000%)
Σ (yi / LELi) = (58.2825 / 2.50) + (26.4110 / 6.00) + (15.3065 / 1.10) = 23.3130 + 4.4018 + 13.9150 = 41.6298

LELmezcla = 100 / 41.6298 = 2.4021% v/v ≈ 2.40% v/v (24021 ppmv)

3.3. Cinética de Evaporación de Acetona y Concentración en Recinto
1. P*: log10 P* = 7.02447 - [1161.0 / (25.0 + 224.0)] = 2.36182
   P* = 102.36182 = 230.048 mmHg = 30670.6 Pa
2. K: K = 0.00478 · (0.200)0.78 = 0.00478 · 0.28473 = 0.001361 m/s
3. W: W = [58.080 · 0.001361 · 2.50 · 30670.6] / [8.31446 · 298.15] = 6061.34 / 2478.95 = 2.44518 g/s (2445.18 mg/s)
4. Css: Css = 2445.18 / [0.450 · 0.650] = 2445.18 / 0.2925 = 8359.59 mg/m3
5. Css [ppmv]: (8359.59 · 24.45) / 58.080 = 3519.15 ppmv
3.4. Diagnóstico Comparativo Ocupacional y ATEX
• Índice I = 3519.15 ppmv / 250.0 ppmv = 14.08
Dictamen Forense: Supera en 14.08 veces el TLV-TWA. Condición crítica: narcosis aguda, riesgo vital. Detención inmediata y uso obligatorio de ERA/SCBA.

• % LEL = (3519.15 / 25000) × 100% = 14.08% del LEL
Dictamen ATEX: No alcanza el 100% LEL, pero rebasa el límite precautorio admisible del 10%. Cualquier corte en la extracción forzada elevará la mezcla al rango inflamable catastrófico.
